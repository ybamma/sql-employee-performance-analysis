# SQL Employee Performance & Bonus Analysis

This project analyzes employee bonus data using SQL to support business decision-making.

## Objectives
- Identify high-performing employees
- Analyze bonus distribution by department
- Practice SQL joins and aggregations

## SQL Concepts Used
- INNER JOIN, LEFT JOIN
- WHERE filters
- GROUP BY and aggregate functions
- Business-driven queries

## How to Use
1. Run `schema.sql` to create tables
2. Run `sample_data.sql` to insert data
3. Execute queries from `queries.sql`

## Use Case
Helps HR and management evaluate employee performance and reward distribution.
